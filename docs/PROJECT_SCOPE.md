# Curated Repository Scope

This directory is a GitHub-oriented project copy, not a byte-for-byte archive of the working directory.

## Kept

- The COMSOL template required to reproduce the model setup.
- Python source used for COMSOL automation, plot export, quantitative comparison, and phase-2 analysis.
- Material configuration and raw input snapshots needed to audit the calculation.
- Verified numerical result tables, pressure regressions, manifests, and final figures.
- Short notes describing assumptions, limitations, and the COMSOL 6.3 runtime workflow.

## Deliberately Excluded

- COMSOL installation files, license files, Java runtime, preferences, and recovery folders.
- Repeated material-specific MPH files from every pressure point.
- Failed diagnostic MPH files and intermediate COMSOL exports.
- Python bytecode and duplicated source snapshots.
- Reference PDFs and unrelated desktop files.

The excluded files are either reproducible from the template and scripts, generated runtime state, or not needed to understand the published result. The original working folders remain outside this curated copy.
